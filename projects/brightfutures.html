BrightFutures Dashboard

Python Selenium Snowflake Snowpipe Tableau

A data pipeline and interactive dashboard that centralizes school data across Southern California — scraped, geo-enriched, warehoused, and visualized — so parents can compare schools on a single pane instead of five browser tabs.

The Challenge

Parents comparing schools in Southern California face a fragmented landscape — performance data on one site, location data on another, tuition on a third. The goal was to pull all of it into one place and make it filterable.

The Approach

1. Dynamic Web Scraping: Used Python and Selenium to automate extraction of school data (name, type, grades, performance metrics, contact info) from multiple California educational portals.

2. Data Enrichment & Geocoding: Enhanced each school record with geographical coordinates using geopy, enabling map-based filtering by proximity.

3. Cloud Warehousing with Snowflake: Loaded the processed dataset into Snowflake using Snowpipe for automated, event-driven ingestion — data stays current without manual re-runs.

4. Interactive Tableau Dashboard: Connected Tableau directly to Snowflake; built a map view, comparison filters, and performance trend charts for end-user exploration.

The Outcome

A self-refreshing school database covering Southern California. Users can filter by district, school type, grade range, and proximity, then compare side-by-side on metrics like enrollment, performance, and location — all in one dashboard.

Technologies Used

  • Python & Selenium — automated web scraping
  • geopy — geocoding for map-based filtering
  • Snowflake & Snowpipe — cloud storage and automated ingestion
  • Tableau — interactive visualizations connected live to Snowflake
