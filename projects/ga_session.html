Google Analytics — BigQuery SQL Analysis

BigQuery SQL Google Analytics

The Context

The Google Merchandise Store sells Google-branded merchandise. The dataset is publicly available in BigQuery and is representative of a real e-commerce analytics workload — nested JSON session records, hit-level events, transaction data, and device/traffic metadata.

The Questions

  • What is the total number of transactions per device browser in July 2017?
  • What is the real bounce rate per traffic source?
  • What was the average product pageviews for users who made a purchase vs. those who didn't?
  • What was the average transactions per purchasing user?
  • What is the average revenue per session?
  • What is the sequence of pages viewed — top landing pages, exit pages, and navigation paths?

The Approach

Each question gets its own SQL query against the bigquery-public-data.google_analytics_sample.ga_sessions_* wildcard table, filtered to July 2017. Results are shown inline with the query, followed by insights and concrete next actions.

1. Total Transactions per Device Browser

SELECT
    device.browser AS browser,
    COUNT(totals.transactions) AS total_transactions
FROM
    `bigquery-public-data.google_analytics_sample.ga_sessions_*`
WHERE
    _TABLE_SUFFIX BETWEEN '20170701' AND '20170731'
    AND totals.transactions IS NOT NULL
GROUP BY
    device.browser
ORDER BY
    total_transactions DESC;

Insights

  • Chrome drives 90%+ of transactions. Safari is the only meaningful secondary browser.
  • Firefox, IE, Edge, and Opera contribute minimally — likely reflect the store's user demographic rather than a technical issue.

Actions

  • Prioritize Chrome and Safari in any checkout-flow QA or A/B test setup.
  • Run cross-browser checkout tests on Firefox/Edge quarterly to catch regressions before they affect volume.

2. Real Bounce Rate per Traffic Source

SELECT
    trafficSource.source AS traffic_source,

FROM

    _TABLE_SUFFIX BETWEEN '20170701' AND '20170731'

Insights

  • Review landing pages for the top-volume high-bounce sources — is the page relevant to the referring context?
  • Suppress or deprioritize ad spend on consistently 100%-bounce sources with no conversion history.

3. Avg Product Pageviews — Purchasers vs. Non-Purchasers

-- Purchasers
SELECT AVG(totals.pageviews) AS avg_pageviews_purchasers
FROM `bigquery-public-data.google_analytics_sample.ga_sessions_*`
WHERE _TABLE_SUFFIX BETWEEN '20170701' AND '20170731'
  AND totals.transactions IS NOT NULL;

-- Non-purchasers
SELECT AVG(totals.pageviews) AS avg_pageviews_non_purchasers
FROM `bigquery-public-data.google_analytics_sample.ga_sessions_*`
WHERE _TABLE_SUFFIX BETWEEN '20170701' AND '20170731'
  AND totals.transactions IS NULL;
SegmentAvg Product Pageviews
Purchasers25.92
Non-purchasers3.45

Insights

  • Purchasers viewed ~7.5x more pages than non-purchasers — buying requires extensive browsing for this store.
  • Non-purchasers at 3.45 pageviews likely didn't find what they wanted or hit a friction point early.

Actions

  • Improve product discovery for users in the 1–5 pageview range — related products, filters, search suggestions.
  • Implement retargeting for users who browsed but didn't convert to recapture intent.

4. Avg Transactions per Purchasing User

SELECT AVG(totals.transactions) AS avg_transactions_per_user
FROM `bigquery-public-data.google_analytics_sample.ga_sessions_*`
WHERE _TABLE_SUFFIX BETWEEN '20170701' AND '20170731'
  AND totals.transactions IS NOT NULL;
Avg Transactions per User
1.04

Insights

  • Almost all purchasing users make exactly one transaction per session — very little multi-purchase behavior.

Actions

  • Introduce bundle offers or "frequently bought together" modules at checkout to increase multi-item transactions.
  • Test a post-purchase upsell page to capture incremental revenue from committed buyers.

5. Avg Revenue per Session

SELECT AVG(totals.transactionRevenue) / 1000000 AS avg_revenue_per_session
FROM `bigquery-public-data.google_analytics_sample.ga_sessions_*`
WHERE _TABLE_SUFFIX BETWEEN '20170701' AND '20170731'
  AND totals.transactionRevenue IS NOT NULL;
Avg Revenue per Session ($)
120.76

Insights

  • $120.76 average order value is healthy for branded merchandise — likely driven by apparel bundles.

Actions

  • Test threshold-based promotions (e.g., free shipping above $150) to nudge AOV upward.
  • Segment by traffic source to identify which sources drive high-AOV sessions vs. low-AOV ones.

6. Sequence of Pages Viewed

A. Create a Temp Table

CREATE TEMP TABLE temp_ga_sessions AS
SELECT
    fullVisitorId,
    visitId,
    visitStartTime,
    hits.page.pagePath AS page_path,
    hits.hitNumber AS hit_number
FROM
    `bigquery-public-data.google_analytics_sample.ga_sessions_*`,
    UNNEST(hits) AS hits
WHERE
    _TABLE_SUFFIX BETWEEN '20170701' AND '20170731'
ORDER BY
    fullVisitorId, visitStartTime, hit_number;

B. Top Landing Pages

SELECT page_path, COUNT(*) AS session_count
FROM temp_ga_sessions
WHERE hit_number = 1
GROUP BY page_path
ORDER BY session_count DESC
LIMIT 5;

C. Top Exit Pages

WITH last_hits AS (
    SELECT fullVisitorId, visitId, MAX(hit_number) AS last_hit_number
    FROM temp_ga_sessions GROUP BY fullVisitorId, visitId
)
SELECT s.page_path, COUNT(*) AS session_count
FROM temp_ga_sessions s
JOIN last_hits lh
  ON s.fullVisitorId = lh.fullVisitorId
  AND s.visitId = lh.visitId
  AND s.hit_number = lh.last_hit_number
GROUP BY s.page_path
ORDER BY session_count DESC
LIMIT 5;

D. Common Navigation Paths

WITH paths AS (
    SELECT fullVisitorId, visitId,
        STRING_AGG(page_path, ' -> ' ORDER BY hit_number) AS navigation_path
    FROM temp_ga_sessions GROUP BY fullVisitorId, visitId
)
SELECT navigation_path, COUNT(*) AS path_count
FROM paths GROUP BY navigation_path
ORDER BY path_count DESC LIMIT 5;

E. Avg Hits per Session

SELECT AVG(hit_count) AS average_hits_per_session
FROM (
    SELECT fullVisitorId, visitId, COUNT(*) AS hit_count
    FROM temp_ga_sessions GROUP BY fullVisitorId, visitId
);
Avg Hits per Session
4.53

Summary Recommendations

  • Home page is both the top landing and top exit page — users arrive, don't find a clear path, and leave. Improve above-the-fold navigation hierarchy.
  • YouTube brand page drives high traffic but also high exits — product discovery on that page is likely weak. Add cross-links to related apparel.
  • Basket exits (1,905) represent recoverable abandonment — email/retargeting sequences targeting basket abandoners should be high ROI.
  • 4.53 avg hits per session is moderate — interactive elements, recommendation carousels, or guided search could increase exploration depth among non-purchasers.
