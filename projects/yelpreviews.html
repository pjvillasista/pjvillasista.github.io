Yelp Reviews Ranking Algorithm

Python VADER Sentiment Linear Regression SQL Tableau

A composite ranking model that combines star ratings, review volume, and VADER sentiment scores to rank Yelp businesses more reliably than stars alone — then maps the results in an interactive Tableau dashboard.

The Challenge

A 4.5-star restaurant with 8 reviews should not outrank a 4.2-star restaurant with 2,000. Yelp's default ranking conflates recency, ad spend, and raw star ratings in ways that bury genuinely well-regarded businesses. The goal was to build a transparent, data-driven ranking that weights star rating, review volume, and actual sentiment from review text.

The Approach

1. Data Collection: Pulled Yelp business and review data (name, category, location, star rating, review count, review text) via the Yelp dataset.

2. Sentiment Scoring (VADER): Applied VADER (Valence Aware Dictionary and sEntiment Reasoner) to each review's text to extract a compound sentiment score. VADER is well-suited to short, informal text — exactly what Yelp reviews look like.

3. Composite Ranking Model (Linear Regression): Used linear regression to fit a composite score from three inputs: average star rating, log-transformed review count, and average VADER sentiment score. The log transform on review count prevents a business with 10,000 reviews from drowning out everything else.

4. SQL Analysis: Queried the scored dataset to produce ranked lists by category and neighborhood, validate distributions, and identify edge cases.

5. Tableau Dashboard: Built a map-based dashboard showing ranked businesses geographically, with filters by category, city, and composite score range.

The Outcome

A more defensible business ranking that surfaces consistently well-reviewed businesses over flash-in-the-pan high-stars-low-volume ones. The map dashboard lets users explore top performers by neighborhood and category with a clear composite score backing each ranking.

Technologies Used

  • Python (VADER, sklearn, Pandas) — sentiment analysis and regression modeling
  • SQL — aggregation, ranking queries, and data validation
  • Tableau — geographic map dashboard with composite score filters
