Helldivers 2 — Player Feedback NLP

Python BERTopic Apache Airflow Steamworks API Tableau

An automated pipeline that pulls Steam player reviews weekly via the Steamworks API, applies BERTopic topic modeling to surface recurring issues, and visualizes sentiment trends so a development team can prioritize what players actually care about.

The Challenge

Helldivers 2 launched to massive player numbers but quickly accumulated thousands of Steam reviews reporting server crashes, connectivity failures, and balance issues. Reading reviews manually doesn't scale — the question was how to turn 50K+ unstructured text reviews into a prioritized list of issues the development team could act on.

The Approach

1. Automated Data Collection (Airflow + Steamworks API): Built an Apache Airflow DAG that runs weekly, pulling new reviews via the Steamworks API and appending them to a local dataset. Consistent data collection without manual intervention.

2. NLP Topic Modeling (BERTopic): Applied BERTopic — a transformer-based topic modeling library — to cluster reviews into coherent topics. BERTopic uses sentence embeddings rather than bag-of-words, so it surfaces semantic meaning rather than just keyword frequency. Topics like "server connectivity", "crash on startup", and "weapon balance" emerged without manual labeling.

3. Sentiment Analysis: Scored each review for sentiment polarity. Combined with the topic clusters, this shows not just what players talk about, but whether they're angry or neutral about each topic.

4. Tableau Executive Dashboard: Built filterable dashboard views: sentiment over time, top complaint topics by volume, and per-patch trend lines so the dev team can see if fixes actually moved sentiment.

The Outcome

A self-updating feedback intelligence tool. The dashboard shows server performance and content variety as the top negative sentiment drivers, providing the development team a clear, data-backed signal about where to focus patch work.

Technologies Used

  • Python — data pipeline, API calls, preprocessing
  • BERTopic — transformer-based NLP topic modeling
  • Apache Airflow — weekly pipeline scheduling
  • Steamworks API — review data source
  • Tableau — executive sentiment dashboard
